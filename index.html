About

      
This is a fully client-side mock SAML 2.0 Identity Provider. It can:

      
    
        
  • Accept an SP-initiated AuthnRequest (HTTP-Redirect binding) and parse the ACS URL, issuer and InResponseTo.
    • 
        
  • Generate signed SAML Response/Assertion payloads (RSA-SHA256, exclusive c14n, enveloped).
    • 
        
  • Produce IdP metadata and a self-signed X.509 signing certificate.
    • 
      

      
Keys and configuration are stored only in your browser's localStorage. Nothing is sent anywhere except to the ACS URL you configure.

      
Signatures are produced with xmldsigjs and certificates with @peculiar/x509.

      
Not for production. The bundled demo private key is public. This tool is for local integration testing only.

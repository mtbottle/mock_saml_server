Mock OIDC Provider

A fully static, client-side OpenID Connect mock for integration testing. Like the mock SAML IdP, it needs no backend — host it on GitHub Pages and point your app at it.

Implicit flow only.

A static host cannot accept the server-to-server POST /token that the authorization-code flow requires, so this mock implements the OAuth 2.0 implicit flow: it signs an id_token in the browser and returns it via the redirect fragment (response_type=id_token or id_token token). It works with SPAs / clients that accept implicit responses, but not with confidential server-side SPs (e.g. Sentry) that exchange a code at a token endpoint.
